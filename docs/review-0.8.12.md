# 0.8.12 标签与启动生命周期

关闭最后一个标签默认保留阅读窗口，正文区域显示共享应用 logo。设置 → 通用增加「关闭最后一个标签时退出应用」，默认关闭；行为设置保存到既有 preferences.json，不重建正文排版。标签正文和关闭按钮显式使用小手指针，关闭按钮继续阻止点击传播。

欢迎页只在首次启动自动打开；帮助 → 碧果使用指南仍可手动打开。pecan-config 使用独立 launched 标记和文件独占创建，支持 macOS、Windows、Linux 原生配置目录；已有设置或最近历史的升级安装视为已启动。恢复默认设置不清除此记录。没有可写配置目录时仍可启动应用，日志记录错误并跳过自动欢迎页。

空窗口是正常状态。关闭全部取消待完成的加载与搜索、释放文档和文件监视、清空搜索结果、恢复阅读窗口焦点；保留工作区以便重新打开文件。查找、复制、导出、原版 PDF 查看及标签切换在无文档时安全停用。打开文件、最近文件和帮助均保留入口。

验证：260 项工作区测试通过，11 项环境专项默认 ignored，其中 10 项为既有专项，新增的首帧 logo Metal 专项已单独执行通过；rustfmt、全目标全特性严格 Clippy、warnings-as-errors rustdoc 通过。新增回归覆盖既有配置默认不退出和保存、首次启动／重置／并发、空窗口操作、加载与搜索取消、重新打开，以及实际标签关闭按钮的退出行为。

三份验收文档 word-table-lists、word-inline-borders、callout-alignment 的 Word／PDF／HTML／Markdown 共 12 个文件与 0.8.11 逐字节相同；导出、文档、格式化、高亮、资源、导入、Mermaid、数学、网络、vendor 及 samples 的源码与 0.8.11 源码包一致。未引入新的依赖、缓存、常驻任务或文档解析路径。验收材料：本地 QA/2026-11-06/pecan-tabs-0.8.12/。
