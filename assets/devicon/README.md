# Devicon language marks

Source: https://github.com/devicons/devicon/tree/v2.18.0/icons
License: MIT, reproduced in ../../licenses/MIT-Devicon.txt.

Only 38 language/database marks are included; no icon font, JavaScript or network loader.
SVG geometry is retained from the official plain/original variants (C uses line).
Paint is normalized to #777777 for monochrome export. GPUI tints the SVG mask
with the reading theme's secondary text color. Irrelevant Markdown text CSS is removed.
The upstream URLs and SHA-256 hashes are recorded in upstream.json.

SQL uses Azure SQL Database; explicit database fence names use their own marks.
Azure SQL's original cylinder, top and SQL paths are converted to an even-odd
monochrome silhouette; the inner top and SQL letters are transparent cutouts so
GPUI's alpha tint preserves those details. The original gradients are omitted.
