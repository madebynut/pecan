# Generic language mark

code-xml.svg is the Lucide CodeXml (</>) icon embedded by gpui-kit-assets 0.9.0.
The SVG geometry is unchanged; currentColor is normalized to #777777 for export.
It is used when a code language has no dedicated Devicon mark, including unknown languages
and unlabelled code. GPUI tints it with the current theme.
