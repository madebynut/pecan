# Markdown 基础样式验收

正文、标题、引用、列表、表格及提示块支持 **加粗**、*斜体*、~~删除线~~，也支持 ***加粗斜体*** 和 **~~加粗删除线~~**。

## 标题中的 `**加粗**`、`*italic*` 与 `~~旧版~~`

行内 code：`**接口文档**`、`*version*`、`~~deprecated~~`、`***both***`。无空格相邻：正文`**接口文档**`结尾。相邻胶囊：`**加粗**` `~~旧版~~`。

字面保真：`snake_case`、`snake\_case`、`[link](url)`、`<b>html</b>`，单词中的下划线不作为强调。

> 引用 **加粗**、*斜体*、~~删除线~~、`**code 加粗**`。

- 列表 **加粗**、*斜体*、~~删除线~~。
- [x] 完成：`**重要结果**`。
- [ ] 待办：`~~旧方案~~`。

| 场景 | 示例 |
| --- | --- |
| 普通单元格 | **加粗**、*斜体*、~~删除线~~、`**code 加粗**` |
| 显式换行 | **第一行**<br>*第二行*<br>`~~旧版~~` |

> [!NOTE] **自定义标题** *italic* ~~旧版~~ `**version**`
> 正文支持 **加粗**、*斜体*、~~删除线~~、`**code 加粗**`。
>
> - 列表中的 `~~旧方案~~`。

::: **自定义高亮标题** *italic* ~~旧版~~
正文支持 **加粗**、*斜体*、~~删除线~~ 与 `***加粗斜体***`。
:::

:::
无标题提示：**加粗**、*斜体*、~~删除线~~ 和 `**接口文档**`。

- 列表支持 **强调**。
:::

代码块只做语言语法高亮，不解析其中的 Markdown 标记：

```text
**literal bold** *literal italic* ~~literal strike~~
snake_case
```

Mermaid 块按 Mermaid 自身的语法渲染，源码保持原样：

```mermaid
flowchart LR
    A[加载文档] --> B[阅读与导出]
```
