# 图表阅读

在碧果中阅读 `Mermaid` 图表：清晰的布局、克制的工具栏，以及随手可用的源码。

## 设计流程

```mermaid
flowchart LR
    A[阅读文档] --> B[查看图表]
    B --> C[放大细看]
    C --> D[返回正文复制源码]
```

## 阅读细节

| 操作 | 体验 |
| --- | --- |
| 正文 `</>` 图标 | 查看只读源码，再次点击返回图表 |
| 复制图标 | 复制完整原文，成功显示勾选 |
| 点击图表 | 默认打开大窗口，完整高清显示 |
| 底部缩放条 | 缩小、比例、放大、适应窗口；专注看图 |
| 调整窗口大小 | 自动适配，保持清晰 |
| 适应窗口 | 主动放大后恢复完整显示 |
| Escape | 直接返回文档，全屏也适用 |

正文使用白色纸页，`code` 胶囊使用浅灰并带细边框；标题与内容之间保留舒适的留白。
