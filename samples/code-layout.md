# 代码排版与折叠

支持的语言在加载时自动格式化，Tab 菜单选择「自动识别」或 2 / 4 / 8 列后自动重新格式化当前块；其它语言保留原排版，可调整实际 Tab 与参考线。工具栏支持整块折叠和复制，左側可按语法结构折叠，搜索会展开目标。源 Markdown 和导出代码保持原样。

## 2 列空格

```json
{
  "document": "技术方案",
  "reading": {
    "font_size": 16,
    "code_size": 14
  }
}
```

## 4 列空格与注释

```json-ld
{
    "orchMode": "chain",
    "version": 1,
    "providers": [
        {
            "provider": "gps",
            "options": {
                "duration": "30000",
                "needAddress": "true"
            }
        }
    ],
    "compliance": { // 法案受限区域配置
        "enabled": false,
        "url": "文件地址", // JSON 文件地址
        "hash": "xxx", // SHA256
        "size": 1024
    }
}
```

## 制表符

```jsonc
{
	"tab": {
		"description": "此块使用真正的 Tab，可在工具栏切换 2 / 4 / 8 列",
		"url": "https://example.com/path", // 保留注释
	},
}
```

## 长行与嵌套

代码不会自动换行，长行保留水平滚动。展开时不限制高度。

```rust
fn read_document() {
    for title in ["技术方案", "使用指南", "阅读笔记"] {
        if !title.is_empty() {
            println!("{} · 这是一行用于验证水平滚动的长代码：源码完整保留，折叠只是隐藏显示，展开和复制都不会丢失代码。", title);
        }
    }
}
```

## 验收操作

- 打开上方 json-ld 卡片的「缩进宽度」菜单，选择 2 列；正文应立即按 2 列排版。依次切换 4、8 列和自动识别，检查缩进线与文字对应。
- 复制操作在格式化状态复制当前排版，原始状态复制原文。Markdown 源文件和导出内容不因阅读格式化改变。
- 注释、字段顺序、Unicode 和数字写法保持；无效 JSON 提示错误并保留当前代码。格式化受原有输入、输出及复杂度预算限制。
- 切换亮暗主题，语言工具栏与代码正文应有清楚的灰度层次；亮色代码背景为 #FCFCFC、工具栏为 #F4F4F4，暗色代码背景为 #222222、工具栏为 #2A2A2A。
- 保持长代码完整展开，滚动正文查看卡片下边框，确认没有受到配色或格式化改动影响。
