# Configuration formatters

YAML uses pretty_yaml 0.6.0 and yaml_parser 0.3.0 (MIT, Pig Fang), with tiny_pretty 0.2.1 (MIT).
TOML uses taplo 0.14.0 (MIT, Ferenc Tamás). Bounded preflight tokenization uses logos 0.12.1 (MIT / Apache-2.0).
YAML value validation uses yaml-rust2 0.11.1 (MIT / Apache-2.0); source mappings reuse similar 2.7.0 (Apache-2.0).
Their applicable license texts and the licenses of newly linked CST support crates are retained beside this notice.
All formatting runs locally, without a language server, command-line formatter or network request.
